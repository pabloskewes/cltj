# MPHF Strategy Evaluation

Analyzes the performance of different MPHF families (BDZ, GlGh, PTHash) and storage policies (Quotienting) in isolation, before integrating them into the full CLTJ index.

## Data Source

The notebook consumes CSV files generated by the `bench_mphf_hashing` executable.
The data includes build time, query time, bits per key, and load factor ($m/n$) for each tested strategy.

## Usage

The analysis is entirely contained within the Jupyter Notebook:
- [`mphf_hashing_analysis.ipynb`](mphf_hashing_analysis.ipynb)
