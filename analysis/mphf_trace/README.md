# MPHF Trace Analysis

Analyzes the build trace of the MPHF hash overlay to diagnose peeling failures, measure retry distributions, and evaluate fallback strategies for residual 2-cores.

## Data Source

The tool consumes `mphf_trace.jsonl`, which is generated by the `MphfBuildTracer` during the `build-hcltj` process (when compiled with `-DCLTJ_COLLECT_MPHF_BUILD_TRACE=ON`).

Each line in the JSONL represents an event: `node_start`, `try_result` (for every peeling attempt), or `node_end`.

## Usage

The primary entry point for interactive analysis is the notebook:
- [`analysis.ipynb`](analysis.ipynb)

There is also a CLI for quick terminal summaries and batch figure generation:

```bash
python main.py path/to/mphf_trace.jsonl [--figdir DIR] [--no-figures]
```
