# Children Histogram Analysis

Analyzes the distribution of children per node across the metatrie to determine the optimal threshold for the MPHF hash overlay.

## Data Source

The tool consumes `trie_X_YYY.csv` files generated by the `stats-hcltj` executable.
These CSVs contain two columns: `children` (number of children) and `nodes` (how many nodes have exactly that many children).

## Usage

The primary entry point for interactive analysis is the notebook:
- [`analysis.ipynb`](analysis.ipynb)

There is also a CLI for quick terminal summaries and batch figure generation:

```bash
python main.py path/to/csv_dir/ [--figdir DIR] [--thresholds 10 50 100 1000]
```
