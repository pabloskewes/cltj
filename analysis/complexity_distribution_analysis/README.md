# Complexity Distribution Analysis

Statistical analysis comparing empirical intersection cost vs theoretical complexity metrics.

## Data Source

The notebook consumes CSV files generated by the `bench-query-cltj` executable (when compiled with intersection stats enabled).
The data includes the alternation complexity ($\delta$), $q \times \min$, and actual query execution time.

## Usage

The analysis is entirely contained within the Jupyter Notebook:
- [`analyse_results.ipynb`](analyse_results.ipynb)
