# Trie Visualization

Visualizes the structure of the metatrie as a tree using NetworkX and Matplotlib. Useful for verifying the correct construction of full vs partial tries and debugging specific node structures.

## Data Source

The tool consumes `trie_X_YYY_nodes.csv` files generated by the `dump-trie-hcltj` executable.
These CSVs contain the exact node hierarchy: `node`, `parent`, `depth`, `key`, `n_children`, `is_leaf`.

## Usage

The primary entry point for interactive analysis is the notebook:
- [`analysis.ipynb`](analysis.ipynb)

There is also a CLI for batch figure generation:

```bash
python main.py path/to/csv_dir/ [--figdir DIR] [--all-tries]
```
